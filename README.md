# Assignment 2 - ExpressJS Portfolio Website

## Project Description

This project is my personal portfolio website built using Node.js, ExpressJS, and EJS templates.

The website includes four pages: Home, About Me, Projects, and Contact Me.

I used Bootstrap, Font Awesome, and CSS to style the website and make it responsive.

## Technologies Used

- Node.js
- ExpressJS
- EJS Templates
- Bootstrap
- Font Awesome
- HTML and CSS
- Git and GitHub
- Render

## Project Structure

- `app.js` - Main ExpressJS application configuration
- `routes/index.js` - Routes for the portfolio pages
- `views/` - EJS page templates
- `views/partials/` - Shared navbar and footer
- `public/` - CSS and static files
- `bin/www` - Starts the server

## Running the Project

1. Install Node.js.
2. Clone the GitHub repository.
3. Open the project folder in a terminal.
4. Run `npm install`.
5. Run `npm start`.
6. Open http://localhost:3000 in a browser.
