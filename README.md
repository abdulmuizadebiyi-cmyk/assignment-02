# Assignment 2 — ExpressJS Portfolio Website

## Project Description
This project is a personal portfolio website developed using Node.js, ExpressJS, and EJS templates. It includes four pages: Home, About Me, Projects, and Contact Me.

The website uses Bootstrap, Font Awesome, and CSS for responsive design.

## Technologies Used
- Node.js and ExpressJS
- EJS Templates
- Bootstrap and Font Awesome
- HTML and CSS
- Git and GitHub
- Render

## Project Structure
- `app.js` — ExpressJS application configuration.
- `routes/index.js` — Routes for the portfolio pages.
- `views/` — EJS page templates.
- `views/partials/` — Shared navbar and footer.
- `public/` — CSS and static assets.
- `bin/www` — Node.js server startup.

## Running the Project
1. Install Node.js.
2. Clone the repository.
3. Run `npm install`.
4. Run `npm start`.
5. Open `http://localhost:3000`.
